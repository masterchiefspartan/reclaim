# Recovery Frameworks System

**Purpose:** Structured journaling templates that guide users through specific recovery challenges, inspired by Mindsera's mental models but tailored for physical recovery journeys.

**Why This Matters:**
- Reduces "blank page" anxiety
- Ensures consistent, useful data for insights
- Creates a "mental workout" feeling (value)
- Differentiates from generic journaling apps
- Increases engagement and retention

## 1. Framework Philosophy

### From Mindsera: Mental Models
Mindsera uses frameworks like "First Principles Thinking" and "Ikigai" to structure reflection. These work because:
- They provide a **proven structure** for thinking
- They feel like you're getting **expert guidance**
- They produce **actionable insights**
- They're **repeatable** with different results each time

### For RecoverVoice: Recovery Models
Our frameworks must:
- Address **specific recovery challenges** (pain, isolation, fear, motivation)
- Work with **voice input** (conversational prompts)
- Produce data for **pattern detection**
- Feel like **professional support** (PT, therapist, coach)
- Be **phase-appropriate** (Week 1 vs Week 8 are different)

## 2. Core Recovery Frameworks

### Framework 1: Daily Recovery Check-In
**Purpose:** Quick daily status assessment (the "default" framework)
**Duration:** 2-3 minutes
**Best For:** Daily habit, consistent tracking

**Prompts:**
1. "How does your body feel today compared to yesterday?"
2. "On a scale of 1-10, what's your pain level right now?"
3. "What emotion best describes your recovery mindset today?"
4. "What's one small win from the last 24 hours?"

**Data Captured:**
- Pain level (1-10)
- Body comparison (better/same/worse)
- Primary emotion
- Daily win

**AI Response Focus:**
- Validate the current state
- Reference recent trends ("Your pain is down from 7 to 5 this week")
- Celebrate the small win
- Set intention for tomorrow

---

### Framework 2: Pain Processing Protocol
**Purpose:** Work through difficult pain days with structure
**Duration:** 5-7 minutes
**Best For:** High pain days, frustration moments
**Trigger:** Can be suggested when user reports high pain

**Prompts:**
1. "Describe where you feel the pain and what kind of pain it is."
2. "What were you doing when the pain increased? Or did it come without warning?"
3. "How is this pain affecting your mood and thoughts right now?"
4. "What has helped with this type of pain before, even a little?"
5. "What do you need right now - rest, distraction, comfort, or something else?"

**Data Captured:**
- Pain location and type
- Pain trigger (activity/random)
- Emotional impact
- Coping strategies that work
- Current need

**AI Response Focus:**
- Acknowledge the difficulty without minimizing
- Remind them of strategies that worked before (from history)
- Validate that pain affects mood (it's normal)
- Suggest one gentle action based on their stated need
- Remind them this will pass (with evidence from their history if available)

---

### Framework 3: PT Session Reflection
**Purpose:** Process physical therapy appointments
**Duration:** 3-5 minutes
**Best For:** Immediately after PT sessions
**Trigger:** Can be scheduled around PT appointment times

**Prompts:**
1. "How did your PT session go today - what did you work on?"
2. "What felt challenging or frustrating during the session?"
3. "What progress did your PT notice, even if small?"
4. "How are you feeling emotionally after the appointment?"
5. "What's one thing you want to remember from today's session?"

**Data Captured:**
- Session content
- Challenges faced
- Progress noted (by PT)
- Post-session emotions
- Key takeaway

**AI Response Focus:**
- Acknowledge the effort it takes to show up
- Highlight the progress noted
- Validate frustration if present
- Connect today's work to long-term recovery
- Encourage rest/recovery after demanding session

---

### Framework 4: Fear & Worry Inventory
**Purpose:** Name and process recovery fears
**Duration:** 5-8 minutes
**Best For:** Anxious moments, pre-appointment anxiety, setback fears
**Trigger:** Detected anxiety patterns, user request

**Prompts:**
1. "What worry or fear is weighing on you most right now about your recovery?"
2. "When you imagine this fear coming true, what would actually happen?"
3. "What evidence do you have that this fear might NOT come true?"
4. "What would you tell a friend who had this same fear?"
5. "What's one small thing you could do to feel more in control?"

**Data Captured:**
- Primary fear
- Worst case scenario (explicit)
- Counter-evidence
- Self-compassion perspective
- Action step

**AI Response Focus:**
- Normalize the fear (common in recovery)
- Gently examine the evidence
- Reflect their own wisdom back to them
- Suggest the small action step they identified
- Remind them of fears they've overcome before (from history)

---

### Framework 5: Support Network Audit
**Purpose:** Assess and strengthen support systems
**Duration:** 5-7 minutes
**Best For:** Feeling isolated, Week 3-4 (when support fades)
**Trigger:** Isolation mentions, mid-recovery phase

**Prompts:**
1. "Who has been most supportive of your recovery so far?"
2. "Is there anyone you wish was more present or understanding?"
3. "What kind of support do you need most right now - practical help, emotional support, or just someone to listen?"
4. "Who could you reach out to this week, even just to say hello?"
5. "What's one way you've been supporting yourself through this?"

**Data Captured:**
- Key supporters
- Support gaps
- Support needs
- Outreach opportunity
- Self-support recognition

**AI Response Focus:**
- Acknowledge the isolation is real
- Celebrate the support they do have
- Validate that needs change during recovery
- Encourage the specific outreach they identified
- Recognize their self-support as strength

---

### Framework 6: Progress & Gratitude Review
**Purpose:** Combat "recovery feels invisible" with evidence
**Duration:** 4-6 minutes
**Best For:** Weekly review, motivation boost, after milestones
**Trigger:** Weekly cadence, motivation dips

**Prompts:**
1. "Think back to one week ago - what can you do now that you couldn't do then?"
2. "What moment this week made you feel proud, even briefly?"
3. "What's something your body did this week that surprised you?"
4. "Who or what are you grateful for in your recovery journey?"
5. "What are you looking forward to being able to do as you heal?"

**Data Captured:**
- Weekly progress (specific)
- Pride moment
- Body surprise
- Gratitude focus
- Future vision

**AI Response Focus:**
- Reflect their progress back clearly
- Celebrate the pride moment
- Marvel at the body's healing ability
- Acknowledge their gratitude
- Paint a picture of the future they're working toward

---

### Framework 7: Identity & Meaning Making
**Purpose:** Process identity shifts during recovery
**Duration:** 7-10 minutes
**Best For:** Athletes, workers whose identity is affected, longer recoveries
**Trigger:** Identity-related mentions, career/sport concerns

**Prompts:**
1. "How has this injury or recovery changed how you see yourself?"
2. "What parts of your identity feel threatened or lost right now?"
3. "What has this experience revealed about your strength or character?"
4. "If you could talk to yourself one year from now, what would you hope to hear?"
5. "What new understanding or appreciation has come from this difficult time?"

**Data Captured:**
- Identity changes
- Perceived losses
- Discovered strengths
- Future self vision
- Meaning found

**AI Response Focus:**
- Honor the losses and identity shifts
- Reflect their discovered strengths
- Connect current struggle to future growth
- Share that post-traumatic growth is real
- Help them see the bigger picture of their story

## 3. Framework Structure

### Universal Structure

```typescript
interface RecoveryFramework {
  id: string;
  name: string;
  slug: string;
  description: string;
  purpose: string;
  duration: {
    min: number; // minutes
    max: number;
  };
  icon: string; // icon name
  color: string; // theme color
  
  // When to suggest this framework
  triggers: {
    phases?: RecoveryPhase[]; // Week ranges
    emotions?: MoodLevel[];
    keywords?: string[]; // detected in recent entries
    schedule?: 'daily' | 'weekly' | 'post-pt' | 'on-demand';
  };
  
  // The prompts themselves
  prompts: FrameworkPrompt[];
  
  // AI response guidance
  aiGuidance: {
    tone: string;
    focusAreas: string[];
    avoidTopics: string[];
    historyReferences: boolean; // should AI reference past entries?
  };
  
  // Data to extract for analytics
  dataPoints: DataPointDefinition[];
}

interface FrameworkPrompt {
  id: string;
  order: number;
  text: string;
  voicePrompt: string; // slightly different for voice (more conversational)
  followUp?: string; // optional follow-up if response is short
  dataPoint?: string; // which data point this captures
  required: boolean;
}

interface DataPointDefinition {
  key: string;
  type: 'number' | 'text' | 'emotion' | 'boolean';
  label: string;
  // For AI to extract from response
  extractionHint: string;
}
```

## 4. AI Response Guidelines Per Framework

### Framework-Specific System Prompts

Each framework should have tailored AI behavior. Here are the system prompt additions:

#### Daily Check-In AI Guidance:
```
For Daily Recovery Check-In responses:
- Keep response concise (2 paragraphs max)
- Always reference their pain level trend if you have history
- Genuinely celebrate their daily win, no matter how small
- End with a gentle intention for tomorrow
- Tone: Warm, efficient, encouraging
```

#### Pain Processing AI Guidance:
```
For Pain Processing Protocol responses:
- Acknowledge the pain is real and difficult first
- Never minimize or use toxic positivity
- Reference coping strategies that worked before (from their history)
- Validate that pain affects mood - this is normal
- Suggest one gentle, specific action based on their stated need
- Tone: Deeply empathetic, calm, supportive
```

#### PT Session Reflection AI Guidance:
```
For PT Session Reflection responses:
- Acknowledge the effort to show up (PT is hard)
- Highlight any progress mentioned, especially from the PT's perspective
- Validate frustration without dwelling on it
- Connect today's work to their long-term recovery goals
- Encourage appropriate rest after the session
- Tone: Encouraging, proud, forward-looking
```

#### Fear & Worry Inventory AI Guidance:
```
For Fear & Worry Inventory responses:
- Normalize that fear is part of recovery
- Gently examine the evidence they provided
- Reflect their own wisdom back (what they'd tell a friend)
- Support the action step they identified
- Reference fears they've overcome before (from history)
- Tone: Gentle, grounding, empowering
```

#### Support Network Audit AI Guidance:
```
For Support Network Audit responses:
- Acknowledge isolation is real and hard
- Celebrate the support they do have
- Validate that needs change during recovery
- Encourage the specific outreach they identified
- Recognize self-support as a genuine strength
- Tone: Understanding, connecting, empowering
```

#### Progress & Gratitude Review AI Guidance:
```
For Progress & Gratitude Review responses:
- Reflect their progress back clearly and specifically
- Celebrate the pride moment with genuine enthusiasm
- Marvel at the body's healing ability
- Acknowledge their gratitude
- Paint a vivid picture of the future they described
- Tone: Celebratory, hopeful, inspiring
```

#### Identity & Meaning Making AI Guidance:
```
For Identity & Meaning Making responses:
- Honor the losses and identity shifts without rushing past them
- Reflect the strengths they discovered
- Connect current struggle to potential growth
- Share that post-traumatic growth is documented and real
- Help them see the bigger arc of their story
- Tone: Deep, philosophical, honoring
```

## 5. Phase-Specific Framework Recommendations

### Early Recovery (Weeks 1-2)
**Primary:** Daily Check-In, Pain Processing Protocol
**Secondary:** Support Network Audit
**Avoid:** Identity & Meaning Making (too early, still in shock)

### Active Recovery (Weeks 3-6)
**Primary:** Daily Check-In, PT Session Reflection, Fear & Worry Inventory
**Secondary:** Support Network Audit (especially Week 3-4)
**Introduce:** Progress & Gratitude Review (weekly)

### Late Recovery (Weeks 7-12)
**Primary:** Daily Check-In, Progress & Gratitude Review
**Secondary:** Identity & Meaning Making, PT Session Reflection
**Focus:** Future visioning, meaning making

### Extended Recovery (12+ weeks)
**All frameworks available**
**Emphasis:** Identity & Meaning Making, Progress & Gratitude Review
**Reduced:** Pain Processing (hopefully less needed)

## 6. Implementation Specifications

### UI Flow

```
Home Screen
    ↓

    ↓

```

### Analytics Integration

Framework data enables powerful analytics:
- Pain trends over time (from daily check-ins)
- PT progress tracking
- Fear pattern detection
- Support network health
- Progress velocity
- Identity reconstruction journey

### Suggested Frameworks Logic

```typescript
function suggestFramework(user: User, recentEntries: JournalEntry[]): RecoveryFramework[] {
  const suggestions: RecoveryFramework[] = [];
  
  // Always include daily check-in
  suggestions.push(frameworks.dailyCheckIn);
  
  // Check recovery phase
  const phase = calculateRecoveryPhase(user.surgeryDate);
  
  // Check recent pain levels
  const recentPain = getAveragePainLevel(recentEntries, 3); // last 3 days
  if (recentPain > 6) {
    suggestions.unshift(frameworks.painProcessing); // Prioritize
  }
  
  // Check for PT day
  if (isTodayPTDay(user)) {
    suggestions.push(frameworks.ptReflection);
  }
  
  // Check for isolation patterns (Week 3-4)
  if (phase === 'active' && detectIsolationMentions(recentEntries)) {
    suggestions.push(frameworks.supportAudit);
  }
  
  // Weekly progress review
  if (shouldShowWeeklyReview(user)) {
    suggestions.push(frameworks.progressGratitude);
  }
  
  // Detect anxiety patterns
  if (detectAnxietyPatterns(recentEntries)) {
    suggestions.push(frameworks.fearInventory);
  }
  
  return suggestions.slice(0, 4); // Show top 4
}
```

| If User Is Feeling... | Suggest Framework |
|----------------------|-------------------|

| Lonely/isolated | Support Network Audit |
